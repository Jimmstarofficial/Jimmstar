# Description, Chapters & SEO

## Description
1. **First 2 lines (~150 chars)** show above "Show more": restate the value with the main keyword, written naturally.
2. **Paragraph 2–3**: what the video covers, using related search phrases naturally. No keyword stuffing.
3. **Chapters**: they start at `0:00`, need at least 3 chapters of 10s or more each, and use descriptive, keyword-friendly names. Build them from the script's segments, or ask for the timestamps.
4. **Links**: related videos or playlist, socials, and any links the user supplies. Never invent URLs; use `[LINK]` placeholders.
5. **Disclosures**: sponsorship or affiliate notes, if relevant.
6. **Hashtags**: up to 3 at the end (the first 3 appear above the title).

## Tags
10–15 tags: the exact main keyword, close variations, and broader topic terms. Tags matter little, so keep them short.

## Pinned comment
One line that sparks replies (a question or a poll-style choice), plus a pointer to the next video.

Return a ready-to-paste block for each field.
