# Shorts Repurposing

## From an existing script or transcript
1. Find **5–8 moments** that stand alone: a surprising fact, a strong opinion, a before/after, a quick tip or a funny beat.
2. For each one, give: the timestamp range (if known), a **new hook line for the first 1–2 seconds**, a trimmed script of 15–50s, an on-screen text caption, and a loop idea (the ending flows back into the start).

## Original Shorts
Format: **Hook (0–2s) → payoff fast → twist or extra value → loop or CTA**. Aim for under 40s. One idea per Short.

## Rules
- Vertical 9:16, keep key visuals in the centre safe zone, and use burned-in captions.
- Don't open with an intro or a logo.
- Use the related-video link to send viewers to the full long-form video.
- Title: short, curiosity-driven, with 1–2 hashtags at most.
